Conventions

Bilingual columns mirror the front-end field / field_ar pattern. Mutable counts (applicant_count, posted_days) are derived in queries — not denormalized. Status flags are Postgres enums; arrays use text[] with GIN indexes.

Storage

Three buckets: avatars · company_logos (public), cvs (private, signed URLs). Object paths are namespaced by auth.uid(); RLS enforces it.

Row-level security

Owners write their own profile. Companies see applications to their opportunities. Catalog tables (career_paths, assessment_questions, cv_templates) are public-read, admin-write.
